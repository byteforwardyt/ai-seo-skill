# Marketplace search

Use for Amazon and Walmart product search. A Google ranking does not move a marketplace listing. Each marketplace has its own catalog, and the seller account shows the current field limits. Use those limits if they differ from memory.

## Shared rules

- The title should name the product a shopper types: brand, product type, and the few attributes that distinguish it, such as size, color, or count. A title that repeats the same word is stuffing.
- Images should show the real product, on a background the marketplace accepts, including the required main-image rules. Infographic images can answer questions. They cannot replace a clear main image.
- Bullets should answer the decision: what it is, who it fits, what is in the box, and the constraint that would cause a return. Do not write five bullets that repeat the title.
- Backend or hidden search terms are for synonyms the title does not already contain. Do not repeat title words. Do not add competitor brand names, ASINs, or claims the product cannot support. Those are policy problems.
- Price, availability, and the variation theme have to be true. Markup or a feed that disagrees with the buy box is a catalog defect.
- Reviews are from buyers. Do not ask for a positive review in exchange for a benefit the marketplace forbids. Do not review your own listing.

## Amazon

Amazon does not publish a lever called "A10" for sellers to tune. Treat that name as industry slang, not a documented system. COSMO is an Amazon Science query-understanding system. It is not a set of secret listing fields.

What a seller can actually edit:

- Title, bullets, description or A+ content, images, and backend search terms
- Item type, category, and required attributes for that product type
- Variations that are real variations, not a way to combine unrelated products
- Inventory and price, which decide whether the offer is buyable

A+ content helps a shopper decide. It is not a substitute for a title that names the product. Brand Registry is a prerequisite for some content types. Do not tell an unregistered seller to add a module they cannot access.

Measure with the account's search query performance and the business reports, if those reports are available for the account. A third-party rank tracker is a hypothesis.

## Walmart

Walmart search uses the item setup in Seller Center: title, key features, description, images, shelf category, and the attributes that item type requires. Missing required attributes suppress the item. Fix those before rewriting marketing copy.

The rich media and brand pages Walmart offers depend on the program the seller is in. Do not recommend a module the account cannot enable.

## Catalog hygiene

Duplicate listings split reviews and confuse the catalog. Suppress or merge duplicates through the marketplace's process. Do not create a second listing to "test a keyword."

A listing that ranks and converts poorly is a conversion problem. This skill can point at a misleading image or a missing attribute. Hand conversion-rate testing back to the user if they asked only for search visibility, and say that is the boundary.
